# Security Policy

## Supported Versions

VerseLink has not released a stable v1.0.0 yet. Until the first stable release, only the current `main` branch is actively maintained for security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public GitHub issue. Use GitHub's private security reporting feature when available.

We will review valid reports as soon as reasonably possible. Please avoid publicly disclosing the issue until it has been reviewed and any appropriate mitigation has been coordinated.

## What to include

Please include, where possible:

- affected version or commit
- reproduction steps
- security impact
- relevant logs with sensitive values removed
- suggested mitigation, if known

## Secrets

Do not include:

- passwords
- VerseLink credentials
- SCMDB credentials
- API tokens
- Discord webhook URLs
- database passwords
- session cookies
- private keys
