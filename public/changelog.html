Changelog

The latest VerseLink changes, explained briefly and clearly.

VERSION 1.2.3 · 08.09.2026
  • VerseLink v1.2.3 is the first clean public release of the project. It provides the supported baseline for self-hosted deployments, development builds, and future stable releases.
VERSION 1.2.1 · 07.09.2026
  • Fixed duplicate location errors when a UEX terminal shares a name with an existing inventory location.
  • UEX location imports now reconcile both terminal names and external IDs safely.
  • Prevented overlapping UEX sync operations.
  • Improved UEX sync error handling in the MobiGlass Admin Center.
  • Invalid HTML or proxy responses are now shown as clear server errors instead of JSON parsing failures.
  • Stable GitHub releases now automatically create the matching MobiGlass Changelog entry.
  • The generated Changelog entry is committed to main before Discord is notified.
  • Drafts, pre-releases and existing release versions are ignored.
VERSION 1.2.0 · 07.09.2026
  • Blueprint image resolution: Improved Star Citizen Wiki matching, safer image selection and linked fallback images for blueprints without a usable preview.
  • MobiGlass changelog: Added stable release versions, GitHub release notes and a separate view for historical pre-release entries.
  • Discord notifications: Changelog notifications now target actual stable releases and ignore pre-release changes.
  • Quality: Improved Wiki resolver coverage and UI tests; all 98 automated tests pass.
VERSION 1.1.0 · 07.09.2026
  • Blueprint images: Added a dedicated fallback image for blueprints without a verified Star Citizen Wiki preview.
  • Wiki image matching: Improved exact Wiki-page matching and safe image selection for blueprint names and SCMDB identifiers.
  • Wiki links: Fallback images now remain linked to the matching Star Citizen Wiki page when one exists.
VERSION 1.0.0 · 06.09.2026
  • VerseLink Accounts & Authentication: VerseLink now provides independent VerseLink IDs, account registration, Recovery Keys, account recovery, credential rotation and integrated authentication dialogs with additional security protections.
  • SCMDB Connected Services: SCMDB is now managed as a connected service from the MobiGlass profile, with pending and connected states, disconnect/reconnect support, revoked-connection protection and multiple connections per account.
  • Material Inventory: Added shared Group Material Inventory with warehouse locations, quality tracking, contributions, withdrawals, moves, notes, My Contributions filtering, persistent history, UEX-aligned data and home locations.
  • Orders: Added Discord notifications and group webhooks, claim notifications, shareable MobiGlass links, material-based Order IDs, clearer quality display and improved filtering and toolbar presentation.
  • Notifications: Improved polling with visibility/offline pausing, automatic resume, connection backoff and more reliable cached-script handling.
  • Blueprint Inventory: Blueprint data now uses active SCMDB Connected Services, supports multiple connections and Personal Blueprint filtering, with themed filters, restored tooltips, standardized icons and updated image references.
  • Groups & Profiles: Redesigned group and profile dialogs, improved RSI profile synchronization, Account Security, Recovery Key management and SCMDB Connected Services in the profile.
  • MobiGlass UI & Themes: Improved authentication, credential feedback, navigation, inventory identities, VerseLink branding, theme selection and Stanton, Pyro and Nyx backgrounds. The static home connection panel was removed and public and MobiGlass interfaces were standardized to English.
  • About & Changelog: About and Admin navigation was improved, deployed-commit information remains available, and MobiGlass now loads the Changelog through a dedicated endpoint.
  • Admin: Administration now uses VerseLink identities and sessions and includes UEX reference-data synchronization without legacy SCMDB authentication.
30.08.2026
  • Saving an RSI profile URL now starts the public RSI profile sync automatically; manual sync remains available.
  • New orders can optionally be published to Discord through the configured group webhook.
  • Order creators no longer receive their own creation notification, but receive a VerseLink notification when another user claims the order.
29.08.2026
  • Public VerseLink profiles can now be opened directly from Blueprint Inventory and Orders in an embedded mobiGlas view.
  • The profile view stays open so RSI and Discord information, as well as the external RSI link, remain accessible.
  • Public profile names are now linked for blueprint owners, order creators, assignees and contributors.
  • RSI profile information such as avatar, handle, Citizen Record, enlistment date and fluency is displayed; missing Discord details are clearly marked as “Not provided”.
  • Material orders support multiple suppliers with color-coded contribution shares, unique order numbers and mobiGlas/browser notifications.
  • TradeMax routes are limited to 20 entries per page and can be browsed with pagination.
  • Readability and usability were improved across themes, administration, profiles, orders and SCMDB synchronization.
25.08.2026
  • Added an internal VerseLink About view in Mobiglass with product details, available modules, connected services and a legal notice.
  • Integrated the VerseLink logo into the About header to match the other Mobiglass application views.
  • Personal Inventory is marked as in development and visually inactive on the About page.
  • Restored the VerseLink logo as the browser favicon and PWA icon.
  • The existing info icon next to Logout now opens the About view directly; the Changelog remains accessible from there.
  • The About view supports direct hash navigation, browser back/forward navigation and responsive module layout.
21.08.2026
  • Added TradeMax – Cargo Profit Optimizer to calculate profitable routes for ships and star systems using UEX prices, buy stock and sell demand.
  • Routes can be sorted by profit, ROI, SCU, stock, demand, location and data age.
  • UEX data is cached server-side for 30 minutes and can be refreshed manually with “Refresh UEX Data”.
17.08.2026
  • Added a secure, read-only public blueprint search for each group.
  • Group owners can create, copy, regenerate and revoke public links.
  • The public view shows blueprint data only and never exposes owners, user IDs, sink tokens or private account data.
  • Added public search filters for category, subcategory and manufacturer, including SCMDB references.
  • Added the Material Orders page for collaboratively recording and managing required resources.
  • Material orders support claiming, reporting deliveries, quality levels, progress tracking, completion, cancellation and hiding.
  • Partial deliveries are accumulated; delivered and open quantities and the current status are shown automatically.
  • Added an order overview with status filters, material search, active-order prioritization and responsive cards.
  • Added Orders navigation next to Groups in the inventory.
24.07.2026
  • The news ticker and time filters now use the immutable initial import time instead of the latest synchronization time.
  • The news ticker now shows each new blueprint only once per run.
  • The ticker animation now starts at the right edge and travels through the full visible area.
  • The ticker travel distance was corrected to span the full window width.
  • News ticker entries now run one after another without duplicates or a centered starting position.
22.07.2026
  • After token creation, the complete sink URL is displayed automatically and can be copied directly.
  • Global administrators can delete users completely, including sessions, connections, profiles, blueprints and group memberships.
  • Group owners can change their group name directly in Group Management.
  • Changelog updates can be published automatically as formatted Discord webhook messages.
  • Group invitations are valid for seven days and can be configured for one-time or reusable use.
  • The “Newly added (24h)” filter shows the newest blueprints from the last 24 hours.
  • These new blueprints are also displayed in an animated ticker with image and name.
  • Added a “Last 7 days” filter for recently added blueprints; the ticker remains limited to 24 hours.
  • Optimized the mobile header with Groups and Logout buttons for narrow screens.
  • Discord changelog notifications now contain only the lines changed in the respective commit.
21.07.2026
  • Added role and permission logic for members, group owners and global app administrators.
  • Group owners can remove members, transfer ownership and create or revoke invitations.
  • Global administrators can view all groups, manage invitations, remove members, change owners and start material synchronization.
  • Users can be blocked or disabled globally; active sessions are terminated.
  • Invitation codes are shown per group, remain available after a refresh and can be copied.
  • Added a browser favicon for Inventory, Groups, Login and Changelog.
  • The “Armour” category is now consistently displayed as “Armor”.
  • Required materials now link directly to the matching SCMDB mining pages.
19.07.2026
  • Multi-user groups with invitations and owner display
  • Blueprint search, categories, materials and SCMDB deep links
  • Mobile layout and installable PWA support
  • Discord notifications for newly received blueprints
